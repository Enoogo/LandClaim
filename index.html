在线成员

    棋盘大小

    坐标原点在棋盘中心 (0,0) 更改棋盘大小会清空当前棋局，从新的一局开始。
    规则说明

    棋盘与棋子

    • 棋盘是正六边形（默认边长 19，进房间后可用「棋盘大小」随时改），内部全部由正三角形格铺满（边长 n 时共 6n² 个三角格）。
    • 坐标原点 (0,0) 在棋盘正中心：所以小棋盘的棋谱拿到大棋盘上照样能看，落在大棋盘中央。
    • 棋子是棍：一根棍正好占一条三角网格线段（相邻两个网格点之间）。
    • 任何棍都不能与已有棍重合，也不能压在棋盘边框线上。

    落子规则

    • 棋手按 黑→白→红→绿→紫→蓝 轮流落一根棍，没有"停一手"，必须落子（在座几人就几人轮）。
    • 末端规则：新棍必须接在上一手的末端（线头）上——就是上一根棍没有与更早棋子相连的那个端点。线只能向前长，不能接回它的另一端。
    • 新开一串（全盘第一手、围得地盘之后的第一手、或线头被堵死时）：新棍必须与棋盘边框连在一起，或者与任何一根已下的棍相接（仍然不能重合）。
    • 允许把棍下进别人已经围好的地盘里（从边界线连进去）。

    围地 · 抢地

    • 棍连成的线把棋盘分成两块时，面积较小的那块（按三角格数）归最后落子的一方，染成他棋子的颜色（黑白红绿紫蓝）。
    • 在对方地盘里围出一块同样结算：较小的一侧归落子方，程序立即重新染色——这就是抢地。
    • 禁止一步抢地：每次围完地后计数器归零，之后每下一手计数 +1。 当计数为 1（围完地后的第一手）时，在对方已经围的地里围出一块地无效（不能这样落子）； 先在别处下一手、再围就可以。计数 ≥2 时围出来的抢地照常允许，在对方地里落子、围空地也照常允许。
    • 平分不算：任何一次把地分成一样大的两块（不管是空地还是已围住的地）， 都不染色、不计数；这步棋可以下，下一步走「新开一串」。

    终局

    • 不设停手：轮到的一方无处可下时对局结束，三角格多者胜； 认输 = 退出比赛（其余棋手继续下，只剩一人时该人胜，「悔一手」可回退认输）。
    • 手动结束对局也要所有在场玩家弹窗同意才生效，生效后按当前地数结算并自动回放棋谱； 有人不同意则对局继续，按本该轮到的顺序，转给第一个拒绝的人继续下。

    多人约定（联机）

    • 所有申请都以弹窗发给每个玩家：上场申请、悔一手、新对局、结束对局； 悔棋 / 新对局 / 结束对局都要所有在场玩家同意才生效（有人拒绝即作废，提议者可撤销）。
    • 下来：坐着的人随时可以让出座位，棋局不重置；空位谁都能坐上去接替继续下（也可以换别的颜色上场）。
    • 掉线自动下场：30 秒没动静的棋手自动让出座位（棋局保留），新加入的人可以直接接替； 轮到空着的座位自动跳过，棋局绝不卡在掉线那家的回合上。
    • 思考时间（可选）：超过时限的一方被自动请下场（本局不能再上场），别人可接替继续下。
    规则解读："末端"实现为上一根棍未与更早棋子相连的那个端点（线不断向前延伸，可以拐弯）；"比较小的那块面积"实现为新棍把某区域一分为二后较小的那一半。

    棋盘几何：正六边形边长 n = 3n²+3n+1 个网格点 / 9n²+3n 条网格边 / 6n² 个正三角形格（默认 n = 19；坐标原点在棋盘中心）
